# Principles of Computer Music

**[Click here to view the textbook](https://www.cs.cmu.edu/~15322/book)**

_Principles of Computer Music_ is a free online textbook that teaches the technical principles and creative practice of musical computing from a computer science perspective in Python. See [About](about.md) for more details.

This textbook was written by [Chris Donahue](https://chrisdonahue.com) as a companion to CMU's Intro to Computer Music Course (15-322/622).

This textbook is a **work in progress** and expected to be completed at the end of 2026.

This repo only contains the raw content, see the link above for a formatted / readable version. The formatting code will be published at a later time.
